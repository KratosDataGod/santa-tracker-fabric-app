# Artwork

These images were cut from the design mockups supplied for this app. Use only
artwork you own or are licensed to use.

- `hero.webp`: the banner at the top of the dashboard (about 3:1). Replace it
  with `hero.jpg`, `hero.png` or `hero.webp`. Delete it and the app draws its
  own North Pole scene and title instead.
- `title.webp`: the title shown top left in globe view.
- `toys/<code>.webp`: one painting per toy line, named by the line's code
  (`trains`, `bears`, `bricks`, `sleds`, `robots`, `books`, `dolls`, `games`,
  `music`, `dinos`, `kites`, `globes`). A missing file simply leaves the card
  without a painting.
- `stages/gift.webp`, `stages/village.webp`, `stages/world.webp`: the paintings
  on the four stage cards (the sleigh card reuses `toys/sleds.webp`).
